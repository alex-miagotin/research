## 🧠 Python Pet Projects for Kids (Age 12+)

All projects use **Tkinter** (standard Python GUI library), are beginner-friendly, and designed to be fun while teaching logic, design, and a little creativity.

---

### 📁 Folder Structure

```
python-kid-projects/
├── calculator/              # Simple calculator with GUI
├── quiz_game/               # Multiple choice quiz game
├── drawing_app/             # Paint-style drawing program
├── password_generator/      # Fun random password maker
├── to_do_list/              # GUI-based to-do list manager
├── number_guessing_game/    # Number guessing with hints
├── rock_paper_scissors/     # Classic game vs the computer
├── memory_game/             # Match pairs game (flip cards)
├── README.md                # Project overview and guide
```

---

### 🐍 How to Run Projects

Make sure Python is installed (Python 3.8+ recommended). Then from the terminal:

```bash
cd quiz_game
python main.py
```

Or double-click the `.py` file on systems that support it.

## 🎮 Project Ideas

### 🧮 1. **Calculator**
A basic calculator with buttons and display. Supports addition, subtraction, etc.
- Concepts: Events, input, arithmetic

### ❓ 2. **Quiz Game**
A multiple-choice game with a score counter and next-question button.
- Concepts: Lists, loops, conditionals

### 🎨 3. **Drawing App**
Kids can draw with their mouse like MS Paint!
- Concepts: Canvas, mouse events

### 🔐 4. **Password Generator**
Generates random passwords with options for length and complexity.
- Concepts: Random, string operations

### ✅ 5. **To-Do List**
GUI for adding/removing tasks with save/load functionality.
- Concepts: Lists, file I/O

### 🎲 6. **Number Guessing Game**
Guess a number between 1–100. App tells if it's too high or too low.
- Concepts: Random, conditionals

### ✊✋✌️ 7. **Rock Paper Scissors**
Play against the computer with scorekeeping.
- Concepts: Random, GUI updates

### 🧠 8. **Memory Matching Game**
Flip cards and find matching pairs. Great for memory and logic!
- Concepts: Grid, game logic, image handling

## 📦 Requirements

All projects are built using only standard libraries like `tkinter`, `random`, `os`, etc., so no installation is needed beyond Python itself.

Optional (for some games):
```bash
pip install pillow
```

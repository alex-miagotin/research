## 🚀 How to Get Started

1. Clone the repo:
```bash
git clone https://github.com/yourusername/ml-pet-projects.git
cd ml-pet-projects
```

2. Choose a project folder.
3. Follow the instructions in the project’s `README.md`.
4. Run the code using Python 3.8+.

---

## 🔧 Requirements

Install dependencies globally or per-project:
```bash
pip install -r requirements.txt
```

Each subproject has its own `requirements.txt` if needed.

## 🌟 Projects Overview

### 01. 🐶 Dog vs Cat Classifier
Train a model to classify images as dogs or cats using convolutional neural networks.

### 02. ✍️ Handwriting Digit Recognizer
Recognize handwritten digits with the MNIST dataset and neural nets.

### 03. 💬 Chat Sentiment Analyzer
Detect mood (positive/negative/neutral) in a message using NLP.

### 04. 🏡 House Price Predictor
Use regression to estimate house prices based on features.

### 05. 🧪 Pet Personality Detector
Predict a pet's personality based on input features and show in a GUI.

### 06. 🎮 ML Trivia Game
An AI-assisted trivia game that adapts to your favorite categories.

### 07. ❌⭕ Tic-Tac-Toe AI
A fun project where an AI learns to play (and beat you at) tic-tac-toe.
